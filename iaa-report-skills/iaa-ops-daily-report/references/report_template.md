# 运营日常汇报 · 三段式模板

> 用途：把「数据 + 运营群原因」整理成发给小迪确认、再落任务评论的报告。
> **固定 3 段**：① 当前情况分析（**含操作明细**）→ ② 处理思路 → ③ 当前进展。
> `{{...}}` 为待填占位；段下 `<!-- -->` 是生成约束，不输出到正文。

## 核心展示规则（小迪逐轮锁定，务必遵守）
1. **判定/分类口径 = 实际转化数**（回调 `channel=4580 且 event_name 空 且 未 blocked`），门槛 `|Δ转化| ≥ 10`。**不使用排班目标 cap**。新/停/加/减全部按转化判。
2. **操作关键点不单独成段**，并入「一、当前情况分析」，用 `【大盘】`（概览）与 `【操作】`（明细）两个带标签的小块分开，避免和数据糊成一坨。
3. **数据/文字分离 + 每行带前缀标签**：流水 / 指标 / 概览 / 原因 / 口径（大盘块）；操作块每类一行"类别 N（±$流水）：客户 …"。
4. **广告主永远第一**；具体 offer/包 **仅在其流水影响 ≥ $15、或该包是全类主线（如 die）时才点名**，否则只报"客户 ±$X"。
5. **转化数每类只在类别行标一次**；下面每单只写流水 $。
6. **数字必带单位**（`$` 或"转化"），相邻数字用 `、·（）` 隔开，**绝不裸挤**。金额评论内四舍五入到整刀，明细留 JSON。
7. **多家撞同一个包**（停/减/加）→ 合并一行并点名该包 + 一句"⚠ …并看是否同因"。
8. **大日子（操作多/焦点包大）**：`【操作】`里该类一行只留"类别总额 + 焦点包"，逐 offer 明细**缩进一层**（`  - 客户 −$X（offer）`），别把一行撑爆。
9. **二、处理思路 / 三、当前进展 用 1/2/3/4 编号，每条带前缀标签**（对象 / 动作 / 状态），讲具体事，不写空泛原则。
10. **原因只给重点项挂半句**，小项不写；群里没写清的标"**待确认**"并落到处理思路跟进项，**不编**。

# 周报模板（IAA 业务·周度评论）

> 触发词：**"整理下 iaa 业务周度评论 / 周报"**。三段主体与日报一致，**但全量改「日均」口径、受众是老板/业务推进评论、比日报更收敛**。
> 计算：`scripts/weekly_roll.py --end {本周周日} --threshold 10 --indir /tmp/ops --json /tmp/ops/weekly_report.json`
> 发布：**业务推进任务评论**（正式 guid 由小迪指定；测试期同日报走【测试评论】），`--as user`。

## 周报专属规则（在日报"核心展示规则"之上叠加）
- **W1 全量按日均**：转化、流水、**分类**都先 7 天求和再 ÷7 = 日均；门槛沿用日报 **±10 日均转化**（与日报同口径，**不自造周门槛**）。
- **W2 头条**：周总 ÷7 得日均；须与逐日日报卡相加一致（已验证 9.21–9.27 周总 $48,440.70 ÷7 = $6,920.10，与逐日卡分毫不差）。
- **W3 只点名头部**：`〔操作〕`每类**只点名影响最大的 1 个广告主 + 其日均流水**，其余一律归"**多家**"；**影响大的"包"单独点出**（如本周减全集中在 `death.puzzle.ways.to.die`）。小流水不逐一展开。
- **W4 每条结论带数据**：概览/原因/进展各挂 ≥1 个数据锚点，但**不堆全表**（老板版，避免累赘）。
- **W5 定性贴事实**：die 包查假停投是**客户要求暂停（被动）**，**不得写成"主动处置假量"**；"换新包"才体现主动。
- **W6 处理思路/进展**：处理思路以**风险与结构**项为主；业务推进类官方话术（新渠道/测试/融合/供给）**由本人按当期取舍**，默认不硬塞。进展固定 `执行 / 推进 / 待补` 三条。

## 周报三段骨架
**一、当前情况分析**
〔大盘〕· **流水**：日均 $X/日，环比 $Y/日 ±Z/日（±%）；ROI·eCPM　· **概览**：操作 N 项（新a/停b/加c/减d），定性　· **原因**：主因（群播报印证）
〔操作〕（只点名头部，其余归"多家"）
- **减量 −$X/日**：{头部广告主} −$Y/日 领衔，{焦点包单独点出}（多家…）
- **新单 +$X/日**：…　· **加量 +$X/日**：…　· **停单 −$X/日**：…
> 重点（可选）：一句点出最活跃/最值得老板知道的结构性变化
**二、处理思路**　1/2/3 编号（风险与结构为主）
**三、当前进展**　1 执行 · 2 推进 · 3 待补
